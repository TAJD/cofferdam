# llms.txt enrichment + docs precision pass — design

Date: 2026-06-10. Beads: cd-54sh (llms.txt), cd-9rxx (docs precision). Status: approved.

## Problem

1. `docs/public/llms.txt` (generated by `cofferdam gen-docs`, served at
   `https://tajd.github.io/cofferdam/llms.txt`) is stale and thin: it still
   advertises the npm package name deprecated in v0.2.3
   (`npm install --save-dev cofferdam`), carries no version information, omits
   the agent-facing subcommands (`advise`, `advise --diff`, `watch`, `lsp`),
   and links only 3 of the docs-site pages.
2. README.md and MAINTAINERS.md carry product-level instructions that belong
   on the docs site, plus stale facts (MAINTAINERS: "Rust 1.78+" vs the real
   MSRV 1.93; "Phase 1 is in progress" vs Phase 4; a duplicated, outdated
   project-structure block).

## Decisions (user-confirmed)

- **Update process is build-time only.** No runtime npm version check, no
  self-update. The existing machinery is the contract: `build_llms_txt()` in
  `crates/cofferdam-cli/src/gen_docs.rs` is the single source; the pre-commit
  hook's `gen-docs --check` blocks drift; `scripts/version.mjs set X.Y.Z
  --regen` regenerates at release; the docs deploy publishes.
- **README gets a moderate trim**, not a rewrite: CI yaml → one-liner + link;
  Languages deep-dive → new docs page; keep the rest of the structure.

## Design

### 1. `build_llms_txt()` rewrite (cd-54sh)

llmstxt.org shape: H1, blockquote summary **including `Current version:
X.Y.Z`** (from `env!("CARGO_PKG_VERSION")`, same as `checks.json`), then
sections:

- **Install** — `@cofferdam/cofferdam` (corrected), link to the new install
  page for escape hatches.
- **Catalog** — checks.json (canonical, machine-readable), human catalog,
  CLI reference (unchanged).
- **Docs** — links to: reference/advise, output-formats, ci-recipes,
  suppression, ignore, overrides, type-aware-checks, invariants,
  plugin-sdk-guide, doctor.
- **Subcommands** — full current list: check (+ `--robot`), advise,
  advise --diff, baseline, init, explain, fix, watch, doctor, lsp, gen-docs.
  `hello` and `type-host` (internal) are excluded.
- **Agent workflow** — 4-step prompt: advise before edit → make change →
  advise --diff preflight → check --robot; `cofferdam.invariants.toml` is the
  source of architectural truth.

The pointer to `cofferdam agents` (cd-l4se, in flight) is added **during that
branch's merge integration**, never before — llms.txt must not advertise a
command that doesn't exist.

### 2. `scripts/version.mjs` gate extension (cd-54sh)

`--regen` already re-runs full `gen-docs`, so llms.txt regenerates. But
`check` only audits `checks.json`'s `cofferdam_version`. Add an llms.txt
location that parses the `Current version: X.Y.Z` line so a stale llms.txt
fails `version.mjs check <tag>` — the same release gate as every other
version location.

### 3. README moderate trim (cd-9rxx)

- CI section: drop the 13-line workflow yaml; keep
  `npx --yes @cofferdam/cofferdam check` + link to ci-recipes.
- Languages: cut to ~3 lines + link to new `docs/languages.md` (receives the
  Rust-adapter narrative).
- Documentation list: add the llms.txt URL as the agent entrypoint.

### 4. MAINTAINERS precision pass (cd-9rxx)

- Fix MSRV (1.78 → 1.93, matching the CI msrv job), phased-build statuses
  (phases 1–3 shipped, 4 in progress, LSP/SARIF partially shipped early).
- Drop the duplicated project-structure block; link to CLAUDE.md's canonical
  one.
- Move "Binary overrides (npm postinstall)" + air-gapped instructions to
  `docs/install.md` (product-level, belongs on the site); MAINTAINERS keeps a
  pointer.

### 5. New docs pages + nav (cd-9rxx)

- `docs/install.md` — npm install, Node 16+, prebuilt-binary platforms,
  `COFFERDAM_BINARY_PATH`, `COFFERDAM_SKIP_DOWNLOAD`, air-gapped recipe,
  build-from-source MSRV.
- `docs/languages.md` — TS as primary surface; the Rust adapter
  (cofferdam-rust, cd-91zc) as the polylingual proof; future-adapter shape.
- Both added to the VitePress sidebar under "Getting started".

## Error handling / verification

- `gen-docs --check` (pre-commit + CI) byte-compares committed artifacts —
  regenerating `docs/public/llms.txt` and committing it is part of the change.
- Full workspace verification block (build, test, clippy, fmt) +
  `node scripts/version.mjs check` must pass before commit.

## Out of scope

- Runtime version checks / self-update (explicitly declined).
- `cofferdam agents` content (cd-l4se owns it).
- llms-full.txt expansion (YAGNI until an agent consumer asks).
